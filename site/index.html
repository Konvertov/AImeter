What it does

Finds your tools on its own

If Claude Code, Codex, Cursor or another supported tool is installed and signed in, its card simply appears. Nothing to type in.

Limits and resets at a glance

Session, weekly and monthly limits as bars, with a countdown to the next reset. The tightest limit is shown right next to the icon.

Tells you if you will run out

A mark on each bar shows where an even pace would be. If you are spending faster than the limit refills, AI Meter says when it will run out.

Token counts from your own logs

For Claude Code: tokens today and over 30 days, a bar per day and the model you use most. Counted on your computer.

Shows only what you want

Pick the main tool, fold the rest down to their key limits, hide the ones you do not need, show limits as spent or as left.

Quiet and tidy

Light or dark, English or Russian. New versions install themselves while the panel is closed.

AI tools it understands

Most are found automatically. A few need an API key or a one-time sign-in.

The list grows with every version.

How it works

  1. Install and startA small icon appears in the menu bar on Mac or in the tray on Windows.
  2. It looks aroundAI Meter checks which AI tools are signed in on this computer and asks each service for your limits, the same way the tool itself does.
  3. You glance at itClick the icon to see every limit, or just read the number next to it.

Your data stays with you

No server of ours

AI Meter talks only to the AI services themselves. There is nothing in between and nothing is collected.

Sign-ins are only read

The app reads the sign-in your tools already saved. It never changes it, copies it elsewhere or signs you out.

Keys stay on your computer

API keys you add are kept locally: in the system password store on Windows, in a file only your user can read on Mac.

No statistics

The app does not report what you do, which tools you use or how much.

First start

macOS

Open the downloaded file and drag AI Meter to Applications. The first time, right-click the app and choose Open: macOS asks to confirm apps that are not from the App Store.

Windows

Run the installer. If Windows shows “Windows protected your PC”, click More info, then Run anyway. The app installs for your user only and needs no administrator rights.
